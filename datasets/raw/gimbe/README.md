## Aggiornamento

```bash
python3 scripts/run_daily_enrichment.py --only gimbe
```

Nota: la pipeline scarica i PDF dai server pubblici di GIMBE/salviamo-ssn.it.
Il workflow GitHub Actions `daily_enrichment.yml` esegue questo download
automaticamente ogni giorno e committa eventuali aggiornamenti.
